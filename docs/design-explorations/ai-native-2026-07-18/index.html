Analyst Lens — three AI-native directions

Same fixture data (DCF $F$42 IRR with precedents), three genuinely different aesthetics. Not iterations of the current UI — each is a distinct bet on what a finance-native AI copilot surface should feel like. All render at realistic taskpane width (380px) inside each iframe.

A — Command launcher / task-app / keyboard-first
B — Instrument finance cockpit / data-dense cards / trading terminals
C — Marginalia Notion / Things / craft-editorial

A — Command

Launcher palette, task-app restraint, keyboard-first density.

Dark, single-column, command-forward. The selected cell is the hero; everything else is a contextual action or a scannable list row. Keyboard hints are first-class, not footer afterthoughts.

  • Monospace numerals everywhere — finance tools earn trust through numbers
  • Precedents/dependents as a single unified list, kind-signaled by glyph not section headers
  • Bottom command bar is the primary action surface (⌘K pattern)
  • Zero section chrome — content breathes via spacing alone

B — Instrument

Financial-cockpit hierarchy, data-dense cards, trading-terminal confidence.

Light, dense, instrument-panel. Big numeral readout, sparkline-shaped context, every pixel earning its place. Reads like a dashboard a CFO would glance at between meetings.

  • Huge value numeral as the anchor — the cell's "answer" is the visual center
  • Context cards (formula, precedents, risk) as tiles in a modular grid
  • Inline sparkline strip for quick neighbor comparison
  • Status pill + staleness signal baked into the header

C — Marginalia

Notion's editorial calm, Things 3's craft, the feeling of a well-annotated model.

Warm, paper-like, annotation-first. Treats the audit trail as the product — each precedent reads like a margin note. For analysts who think in narrative, not grids.

  • Serif display for the cell address — nods to financial typesetting tradition
  • Precedents rendered as numbered annotations with source-workbook badges
  • Generous whitespace, hairline rules, no cards or boxes
  • Action surface collapses to a single intent line at the bottom
